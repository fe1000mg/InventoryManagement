# 献立ノート セットアップ手順

食費と献立を記録する Web アプリです。在庫ノートと同じように、GitHub Pages で公開して、データは Google スプレッドシートにためます。
スプレッドシートにつなぐ前でも、その端末のブラウザに保存して使えます（お試し用）。

## 1. 公開する（GitHub Pages）

このフォルダ（`kondate`）を、在庫ノートと同じリポジトリに入れたままコミットしてプッシュします。
公開されると、次のアドレスで開けます。

```
https://fe1000mg.github.io/InventoryManagement/kondate/
```

## 2. スプレッドシートを用意する（最初の1回だけ）

1. Google スプレッドシートを新しく作る（名前は自由。例：献立ノート）
2. メニューの「拡張機能」→「Apps Script」を開く
3. 最初から入っているコードを全部消して、`gas/Code.gs` の中身を全部貼り付けて保存
4. 関数の選択で `setup` を選んで「実行」→ 許可の画面が出たら自分のアカウントで許可
   （スプレッドシートに「買い物」「料理記録」「レシピ」「献立予定」「休日」「表記ゆれ辞書」のシートができます）
5. 右上の「デプロイ」→「新しいデプロイ」→ 種類の歯車から「ウェブアプリ」を選ぶ
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
6. 「デプロイ」を押して、出てきた「ウェブアプリの URL」（`https://script.google.com/macros/s/…/exec`）をコピー

## 3. アプリとつなぐ

1. アプリを開いて「設定」タブ → URL を貼り付けて「接続する」
2. その端末にお試しのデータがあれば、スプレッドシートへ送るか聞かれます（サンプルなら「キャンセル」で OK）
3. スマホなど、ほかの端末でも同じ URL を一度貼り付ければ、同じデータを見られます

## コードを直したとき（GAS 側）

`Code.gs` を書き換えたら、「デプロイ」→「デプロイを管理」→ 鉛筆マーク →
バージョンを「新バージョン」にして「デプロイ」。こうすると URL は変わりません。

## 使い方のながれ

- **買い物**：買ったら食材名・数量・単位・金額を入力。同じ食材は自動で合算して平均単価を出します
- **料理を記録**：日付・食事区分・料理名を選んで、使った食材と量を入力（食材は選ぶ形式なので表記ゆれしません）
  - 前に作った料理やレシピがある料理は「材料を読み込む」で一発入力
- **週間献立**：予定の料理（3品まで）と予算を入力。実際の金額・予定どおりかどうか・朝昼晩の積み上げ棒グラフが出ます
  - 平日以外の休み（祝日など）は「祝日・休み」にチェックすると、朝・昼・晩の区分になります
- **レシピ**：オレンジ色になった料理（材料がわからない料理）を登録
- **買い物リスト**：まだ作っていない予定に必要な量 − 家の残り ＝ 買う量
- **グラフ**：1日の食費を食事区分ごとの円グラフで表示
- **設定**：スプレッドシート連携、表記ゆれ辞書（例：卵 → たまご）

## 注意

- 「家の残り」は「買った量 − 記録した量」の目安です。捨てた分や記録し忘れがあるとずれます
- 量は、買い物で使った単位にそろえてください（米は g、たまごは 個 など）
- スプレッドシートの1行目（見出し）は変えないでください
- 将来、在庫ノートと同期するための準備として、食材名・単位はなるべく在庫ノートの品名・単位と同じにしておくと楽です
